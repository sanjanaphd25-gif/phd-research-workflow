
# Project Title: Use of Git in Phd research workflow.

## Overview
This project explores the use of machine learning techniques in healthcare, including disease prediction, medical imaging analysis, and patient data analytics.

## Objectives
- Get familiar with Git
- For the collaboration purpose in my research work.

## Project Structure
- docs/: Research documentation contains analysis_notes.md
- src/: Source code folder containing visaulize_data.py, clean_data.py
- data/: Datasets contains sample_data.csv, cleaned_data.csv
- results/: Outputs and visualizations contains score_plt.png, temperature_humidity_plot.png
- references/: Citations paper1.md, paper2.md

## How to run the project
pip install -r requirements.txt
Run clean_data.py
Run visaulize_data.py

## Expected outputs

After running clean_data.py you should get cleaned_data.csv in data folder.
After successful run visaulize_data.py you should get two plots in the results folder.
